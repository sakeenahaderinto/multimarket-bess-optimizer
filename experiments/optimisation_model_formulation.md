# Mathematical Formulation of the Multi-Market BESS Optimisation Model

This document provides the full mathematical specification of the two-stage stochastic
mixed-integer programme used for battery dispatch planning, together with the
Gaussian copula scenario generation procedure, the Rockafellar-Uryasev CVaR objective,
and the rolling-horizon settlement logic used in the backtest.

---

## 1. System Overview

A single battery energy storage system (BESS) participates simultaneously in
three GB electricity markets:

| Market | Symbol | Unit | Settlement |
|---|---|---|---|
| Day-Ahead (DA) | $p^{DA}$ | £/MWh | Physical charge/discharge schedule |
| Balancing Mechanism (BM) | $p^{BM}$ | £/MWh | Real-time redispatch by ESO |
| Dynamic Containment Low (DCL) | $p^{DCL}$ | £/MW/h | Frequency response capacity reservation |
| Dynamic Containment High (DCH) | $p^{DCH}$ | £/MW/h | Frequency response capacity reservation |

The model is solved once per day over a 48-hour (96 half-hourly period) lookahead horizon. Only the first 24 hours are settled against actual prices; the remaining 24 hours serve as a lookahead buffer.

---

## 2. Notation

### 2.1 Sets

| Symbol | Description |
|---|---|
| $\mathcal{T} = \{0, \ldots, T-1\}$ | Dispatch periods, $T = 96$ (48 hours at 30-min resolution) |
| $\mathcal{T}_{SOC} = \{0, \ldots, T\}$ | SoC index set (one entry per period boundary) |
| $\mathcal{B}$ | Set of batteries (single asset: $b = \texttt{bat\_01}$) |
| $\mathcal{S} = \{0, \ldots, N-1\}$ | Scenario set, $N = 20$ |

### 2.2 Battery Parameters

| Symbol | Value | Description |
|---|---|---|
| $P^{\max}_b$ | 1.0 MW | Rated power |
| $C_b$ | 1.0 MWh | Usable energy capacity |
| $\eta_{RTE}$ | 0.85 | Round-trip efficiency |
| $\eta = \sqrt{\eta_{RTE}}$ | $\approx 0.922$ | One-way efficiency per side |
| $e^{init}_b$ | 0.5 | Initial state of charge (fraction) |
| $N_{cyc}$ | 4,000 | Design cycle life (full equivalent cycles) |
| $C_{rep}$ | £175,000/MWh | Battery replacement cost |
| $\Delta$ | 0.5 h | Period duration |

### 2.3 Derived Parameters

The marginal degradation cost per MWh of throughput is:

$$\kappa = \frac{C_{rep}}{2 \cdot N_{cyc}} = \frac{175{,}000}{2 \times 4{,}000} = £21.875 \text{ / MWh}$$

The factor of 2 accounts for the fact that one full cycle involves one charge and one discharge, each of $C_b$ MWh.

### 2.4 Market/Optimisation Parameters

| Symbol | Value | Description |
|---|---|---|
| $f_{DC}$ | 0.5 | Maximum DC fraction of rated power |
| $\tau_{DC}$ | 0.5 h | DC response duration (one settlement period) |
| $e^{min}$ | 0.1 | Hard SoC lower bound |
| $e^{max}$ | 0.9 | Hard SoC upper bound |
| $e^{term}$ | 0.1 | Terminal SoC floor (end-of-horizon) |
| $\delta_{DC}$ | 8 | EFA block size in periods (4 hours × 2 per hour) |
| $\lambda$ | 1.0 / 0.7 | Weight on expected revenue ($\lambda = 1.0$ is risk-neutral, $\lambda < 1.0$ activates CVaR) |
| $\alpha$ | 0.90 | CVaR confidence level (tail probability) |

### 2.5 Stochastic Price Inputs

For each market $m \in \{DA, BM, DCL, DCH\}$, scenario $s \in \mathcal{S}$, and period $t \in \mathcal{T}$:

$$p^m_{s,t} \in \mathbb{R}$$

These are generated by the Gaussian copula procedure described in Section 4.

## 3. Decision Variables

The model separates decisions into two distinct stages reflecting the physical and temporal sequence of electricity markets:

### 3.1 First-Stage (Scenario-Independent)

Committed before price uncertainty resolves — these are the Day-Ahead physical schedule, Dynamic Containment capacity reservations, and the Balancing Mechanism offer capacity submitted to National Grid ESO before gate closure.

| Variable | Domain | Description |
|---|---|---|
| $x^c_{t,b}$ | $\mathbb{R}_{\geq 0}$ | DA charge power at period $t$ (MW) |
| $x^d_{t,b}$ | $\mathbb{R}_{\geq 0}$ | DA discharge power at period $t$ (MW) |
| $y^L_{t,b}$ | $\mathbb{R}_{\geq 0}$ | DC Low capacity at period $t$ (MW) |
| $y^H_{t,b}$ | $\mathbb{R}_{\geq 0}$ | DC High capacity at period $t$ (MW) |
| $v^{off}_{t,b}$ | $\mathbb{R}_{\geq 0}$ | BM offer capacity committed at period $t$ (MW) |
| $z_{t,b}$ | $\{0,1\}$ | Charge mode indicator (1 = charging, 0 = discharging) |

### 3.2 Second-Stage (Scenario-Dependent Recourse)

Resolved after observing the price scenario realization in real time — accepted BM volume and the resulting scenario-specific State-of-Charge trajectories.

| Variable | Domain | Description |
|---|---|---|
| $v_{t,b,s}$ | $\mathbb{R}_{\geq 0}$ | BM dispatch accepted in scenario $s$ at period $t$ (MW) |
| $e_{t,b,s}$ | $\mathbb{R}_{\geq 0}$ | State of charge in scenario $s$ at SoC index $t$ (fraction) |
| $\zeta$ | $\mathbb{R}$ | Value-at-Risk ($\text{VaR}_\alpha$) threshold (when CVaR is active) |
| $u_s$ | $\mathbb{R}_{\geq 0}$ | Scenario revenue shortfall below $\zeta$ (when CVaR is active) |

## 4. Gaussian Copula Scenario Generation

Price scenarios are generated using a Gaussian copula to preserve realistic cross-market dependence. The procedure runs once per day before the MIP is solved.

### 4.1 Historical Correlation Estimation

Let $\mathbf{r}^m_t$ denote the historical realised price in market $m$ at period $t$. Spearman (rank) correlation is estimated from data up to the backtest date to prevent leakage:

$$\hat{\rho}^S_{ij} = \text{Corr}_{Spearman}\!\left(\mathbf{r}^i, \mathbf{r}^j\right), \quad i,j \in \{DA, BM, DCL, DCH\}$$

This is then converted to the Gaussian copula correlation via the exact mapping for elliptical distributions (van der Waerden's formula):

$$\hat{\rho}^G_{ij} = 2 \sin\!\left(\frac{\pi}{6} \hat{\rho}^S_{ij}\right)$$

yielding a $4 \times 4$ positive semi-definite matrix $\mathbf{R}$.

### 4.2 Cholesky Decomposition

Factorise:

$$\mathbf{R} = \mathbf{L}\mathbf{L}^\top$$

where $\mathbf{L}$ is the lower-triangular Cholesky factor.

### 4.3 Correlated Uniform Draws

Draw independent standard normals:

$$\mathbf{Z} \in \mathbb{R}^{N \times T \times 4}, \quad Z_{s,t,m} \overset{iid}{\sim} \mathcal{N}(0,1)$$

Apply the Cholesky transform across markets (last axis):

$$\mathbf{X} = \mathbf{Z} \mathbf{L}^\top \in \mathbb{R}^{N \times T \times 4}$$

Transform to correlated uniform marginals via the standard normal CDF $\Phi$:

$$\mathbf{U} = \Phi(\mathbf{X}) \in [0,1]^{N \times T \times 4}$$

Each $U_{s,t,m}$ is marginally Uniform$(0,1)$ and jointly correlated across markets via $\mathbf{R}$.

### 4.4 DC EFA Block Enforcement

DC prices clear at the 4-hour EFA block level. To enforce block-constant draws, the $U$ value for DC markets is replaced by the draw at the first period of each block, tiled across all 8 periods:

$$U_{s,t,m} \leftarrow U_{s, t_0(t), m} \quad \text{for } m \in \{DCL, DCH\}$$

where $t_0(t) = 8\lfloor t/8 \rfloor$ is the block start period.

### 4.5 Quantile Function Mapping

Quantile forecasts $\hat{q}^m_{10,t}$, $\hat{q}^m_{50,t}$, $\hat{q}^m_{90,t}$ from the trained LightGBM models are used to map each $U_{s,t,m}$ to a price via piecewise-linear interpolation over the central 80% predictive interval:

$$p^m_{s,t} = \begin{cases}
\hat{q}^m_{10,t} + \left(\hat{q}^m_{50,t} - \hat{q}^m_{10,t}\right) \cdot \dfrac{U_{s,t,m}}{0.5} & \text{if } U_{s,t,m} < 0.5 \\[8pt]
\hat{q}^m_{50,t} + \left(\hat{q}^m_{90,t} - \hat{q}^m_{50,t}\right) \cdot \dfrac{U_{s,t,m} - 0.5}{0.5} & \text{if } U_{s,t,m} \geq 0.5
\end{cases}$$

For DC markets, the quantile forecasts are themselves block-averaged prior to this mapping to ensure block-constant forecast values:

$$\hat{q}^{DC}_{k,t} \leftarrow \frac{1}{8}\sum_{j=0}^{7} \hat{q}^{DC}_{k,\, t_0(t)+j}$$

The result is $N = 20$ scenario arrays, each of shape $(N, T)$, bounded within $[\hat{q}^m_{10,t},\, \hat{q}^m_{90,t}]$.

## 5. Optimisation Model

### 5.1 Objective Function & CVaR

Let $R(s)$ denote the net operational revenue realized in scenario $s \in \mathcal{S}$:

$$R(s) = \sum_{t \in \mathcal{T}}\sum_{b \in \mathcal{B}} \left[ p^{DA}_{s,t}\left(x^d_{t,b} - x^c_{t,b}\right) + p^{BM}_{s,t} v_{t,b,s} + p^{DCL}_{s,t} y^L_{t,b} + p^{DCH}_{s,t} y^H_{t,b} - \kappa\left(x^c_{t,b} + x^d_{t,b} + v_{t,b,s}\right) \right] \Delta$$

The objective maximizes a convex combination of expected net revenue and Rockafellar-Uryasev Conditional Value-at-Risk (CVaR):

$$\max \quad \lambda \cdot \underbrace{\left(\frac{1}{N}\sum_{s \in \mathcal{S}} R(s)\right)}_{\text{Expected Net Revenue } \mathbb{E}[R]} + (1 - \lambda) \cdot \underbrace{\left[ \zeta - \frac{1}{(1 - \alpha) N} \sum_{s \in \mathcal{S}} u_s \right]}_{\text{CVaR}_\alpha(R)}$$

$$\text{subject to} \quad u_s \geq \zeta - R(s), \quad u_s \geq 0 \qquad \forall s \in \mathcal{S}$$

- When $\lambda = 1.0$, the model is **risk-neutral**, maximizing mean revenue across scenarios.
- When $\lambda < 1.0$ (e.g. $\lambda = 0.7, \alpha = 0.90$), the model hedges against downside price risk by penalizing revenue shortfalls in the worst $(1-\alpha)$ scenario tail.

### 5.2 SoC Dynamics

Initial condition:

$$e_{0,b,s} = e^{init}_b \qquad \forall b \in \mathcal{B},\, s \in \mathcal{S}$$

Energy balance for $t \geq 1$:

$$e_{t,b,s} = e_{t-1,b,s}
+ \frac{\eta\, x^c_{t-1,b}\,\Delta}{C_b}
- \frac{\left(x^d_{t-1,b} + v_{t-1,b,s}\right)\Delta}{\eta\, C_b}
\qquad \forall t \in \mathcal{T}_{SOC}\setminus\{0\},\, b,\, s$$

The one-way efficiency $\eta = \sqrt{\eta_{RTE}}$ is applied asymmetrically: charging stores $\eta$ of consumed energy; discharging requires $1/\eta$ of stored energy per unit delivered. This correctly yields $\eta^2 = \eta_{RTE}$ over a full cycle.

### 5.3 SoC Bounds

$$e^{min} \leq e_{t,b,s} \leq e^{max} \qquad \forall t \in \mathcal{T}_{SOC},\, b,\, s$$

$$e^{min} = 0.1, \quad e^{max} = 0.9$$

### 5.4 Power Capacity and BM Recourse Bounds

All simultaneous market commitments must not exceed rated power in any scenario:

$$x^c_{t,b} + x^d_{t,b} + v_{t,b,s} + y^L_{t,b} + y^H_{t,b} \leq P^{\max}_b
\qquad \forall t \in \mathcal{T},\, b,\, s$$

The second-stage BM dispatch is coupled to the first-stage offer capacity:

$$v_{t,b,s} \leq v^{off}_{t,b} \qquad \forall t \in \mathcal{T},\, b,\, s$$

### 5.5 Mutual Exclusivity and Mode Constraints

A binary variable $z_{t,b} \in \{0,1\}$ enforces mutual exclusivity between charging and discharging modes:

$$x^c_{t,b} \leq P^{\max}_b \cdot z_{t,b} \qquad \forall t,\, b$$

$$x^d_{t,b} \leq P^{\max}_b \cdot (1 - z_{t,b}) \qquad \forall t,\, b$$

$$v^{off}_{t,b} \leq P^{\max}_b \cdot (1 - z_{t,b}) \qquad \forall t,\, b$$

$$v_{t,b,s} \leq P^{\max}_b \cdot (1 - z_{t,b}) \qquad \forall t,\, b,\, s$$

### 5.6 DC EFA Block Consistency

Dynamic Containment capacity is auctioned at the 4-hour EFA block level; the committed MW cannot change within a block. Let $t_0(k) = 8k$ for block $k \in \{0, 1, \ldots, T/8 - 1\}$:

$$y^L_{t,b} = y^L_{t_0(k),b} \qquad \forall t \in \{t_0(k)+1,\ldots,t_0(k)+7\},\, b$$

$$y^H_{t,b} = y^H_{t_0(k),b} \qquad \forall t \in \{t_0(k)+1,\ldots,t_0(k)+7\},\, b$$

### 5.7 DC Capacity Cap

Total DC commitment is bounded to a fraction of rated power:

$$y^L_{t,b} + y^H_{t,b} \leq f_{DC} \cdot P^{\max}_b \qquad \forall t,\, b$$

With $f_{DC} = 0.5$, at most 50% of rated power can be reserved for DC across both services.

### 5.8 DC SoC Headroom Constraints

When DC capacity is committed, the battery must hold enough stored energy to respond fully in either direction for the duration $\tau_{DC}$ in every scenario:

**Discharge headroom** (DC Low requires energy above $e^{min}$):

$$e_{t,b,s} \geq e^{min} + \frac{y^L_{t,b}\,\tau_{DC}}{\eta\, C_b}
\qquad \forall t \in \mathcal{T},\, b,\, s$$

**Charge headroom** (DC High requires space below $e^{max}$):

$$e_{t,b,s} \leq e^{max} - \frac{y^H_{t,b}\,\tau_{DC}\,\eta}{C_b}
\qquad \forall t \in \mathcal{T},\, b,\, s$$

### 5.9 Terminal SoC Constraint

To prevent end-of-horizon depletion, a terminal floor is imposed:

$$e_{T,b,s} \geq e^{term} = 0.1 \qquad \forall b,\, s$$

## 6. Revenue Settlement

After the MIP is solved, realised revenue is settled against actual market prices. Only the first $T_{settle} = 48$ periods (24 hours) are settled at each step.

Let $\tilde{p}^m_t$ denote the realised price in market $m$ at period $t$.

**DA revenue** (actual price × net physical position):

$$R^{DA}_t = \tilde{p}^{DA}_t \cdot \left(x^{d*}_{t,b} - x^{c*}_{t,b}\right) \cdot \Delta$$

**BM revenue** (actual price × mean accepted recourse dispatch across scenarios):

$$R^{BM}_t = \tilde{p}^{BM}_t \cdot \left(\frac{1}{N}\sum_{s \in \mathcal{S}} v^*_{t,b,s}\right) \cdot \Delta$$

**DC revenue** (clearing price × reserved capacity):

$$R^{DCL}_t = \tilde{p}^{DCL}_t \cdot y^{L*}_{t,b} \cdot \Delta$$

$$R^{DCH}_t = \tilde{p}^{DCH}_t \cdot y^{H*}_{t,b} \cdot \Delta$$

**Degradation cost**:

$$D_t = \kappa \cdot \left[\left(x^{c*}_{t,b} + x^{d*}_{t,b}\right) + \frac{1}{N}\sum_{s \in \mathcal{S}} v^*_{t,b,s}\right] \cdot \Delta$$

**Daily net revenue**:

$$\Pi_d = \sum_{t=0}^{T_{settle}-1} \left(R^{DA}_t + R^{BM}_t + R^{DCL}_t + R^{DCH}_t - D_t\right)$$

## 7. Rolling-Horizon Backtest

The model is evaluated using a rolling-horizon scheme:

1. **At each day $d$**, construct the 96-period (48-hour) forecast window starting at midnight UTC.
2. **Generate $N$ price scenarios** for all four markets using the copula procedure (Section 4).
3. **Solve the Two-Stage MIP** (Section 5) with a 120-second time limit via HiGHS.
4. **Settle revenue** against actual prices for the first 48 periods only (Section 6).
5. **Carry forward SoC**: the expected ending battery SoC across scenarios at $t = T_{settle}$ is used as $e^{init}$ for day $d+1$:

$$e^{init}_{d+1} = \frac{1}{N}\sum_{s \in \mathcal{S}} e^*_{T_{settle},\, b,\, s}$$

6. **Advance** to day $d+1$ and repeat.

## 8. Limitations & Academic Disclosures

1. **Balancing Mechanism Full-Acceptance Simplification:** BM offer capacity $v^{off}_{t,b}$ is committed as a first-stage decision, with real-time recourse dispatch $v_{t,b,s} \le v^{off}_{t,b}$. In physical GB market operations, National Grid ESO dispatches units selectively via Bid-Offer Acceptances (BOAs) based on system merit order and transmission constraints. Modeling BM settlement against the system sell price without explicit BOA acceptance curves serves as an optimistic upper-bound proxy for potential BM revenues and may overstate BM earnings relative to real-world dispatch.
2. **DC Price Resolution:** Dynamic Containment prices clear per 4-hour EFA block, not per 30-minute settlement period. The pipeline forward-fills block-level clearing prices to 30-minute resolution for consistency with the optimisation model.
3. **Decision Timeline:** All features use a minimum 48-period (24-hour) lag to respect the 11:00 UTC D-1 gate closure constraint, preventing target leakage.
4. **Single Asset, Infinite Bus:** The model treats the battery as connected to an infinite bus without local distribution network power flow or locational pricing constraints.

## 9. Model Summary

| Component | Specification |
|---|---|
| Problem class | Two-stage stochastic Mixed-Integer Linear Program (MILP) |
| Solver | HiGHS (via `appsi_highs`) |
| Horizon | 96 periods (48 h) |
| Settlement window | 48 periods (24 h) |
| Scenarios | $N = 20$ Gaussian copula draws |
| First-stage variables | DA charge/discharge ($x^c, x^d$), DC reservations ($y^L, y^H$), BM offer ($v^{off}$), Binary mode ($z$) |
| Second-stage variables | BM dispatch ($v_{s}$), SoC trajectory ($e_s$), CVaR shortfall ($u_s$) |
| Objective | Risk-neutral expected net revenue or Risk-averse CVaR ($\lambda \mathbb{E}[R] + (1-\lambda)\text{CVaR}_\alpha$) |
| Degradation model | Linear throughput cost (£/MWh), proportional to half-cycle replacement cost |
| Efficiency model | Asymmetric one-way: $\eta = \sqrt{\eta_{RTE}}$ per side |
| DC structure | EFA-block auction, 4-hour block-constant commitment |
